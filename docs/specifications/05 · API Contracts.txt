Compact response shape
{
  "dossier_id": "DOS-001",
  "status": "completed",
  "progress": null,
  "result": {
    "vehicle": {"marque": "Dacia", "modele": "Logan", "matricule": "...", "annee":
"2015", "date_sinistre": null},
    "financial": {"status": "complete", "currency": "MAD", "estimated_total": null,
"known_subtotal": 0, "breakdown": {}},
    "parts": [],
    "detections": [],
    "photos": [],
    "report_url": "/api/dossiers/DOS-001/report"
  }
}
The values are schema examples. Missing prices must yield estimated_total: null and
a warning. Financial breakdown carries the five agreed categories. Every photo includes
original/parts/damages/critical annotation URLs; only parts and damages render in React.
HTTP rules
 Scenario                                     Response

 Scan accepted                                202 queued

 Completed dossier scanned again              409 already_analyzed

 Concurrent scan                              409 scan_in_progress

 Unknown dossier                              404

 No valid photos / invalid dossier            422

 Worker unavailable                           503

 Missing AutoEstimate price                   Completed, but financial status incomplete


The backend must validate dossier IDs and file paths to prevent traversal. Progress/ETA are
server-sourced; do not fabricate elapsed percentages in the frontend.
