Orchestration order

    images.
 2. Associate damage masks with parts; calculate severity, including critical-zone rules.
 3. Merge multi-view detections; apply existing decision/priority logic.
 4. Apply any existing saved feedback only if parity requires it; V1 adds no editing.

    recompute aggregates.
