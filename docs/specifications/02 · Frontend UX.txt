02 · Frontend UX
Design direction: compact, quiet, readable. Put identity, estimate and action first; hide
secondary details until clicked. Avoid Streamlit's crowded tab layout.

Screen flow

                                               matricule

                                               / Analyzed / Failed

 Folder card                                   Vehicle label, ID, photo count, scan status
 Analyser                                      Enabled only before first scan or after
                                               failure
 Voir résultat                                 Opens saved output; no recomputation

 Empty/error states                            Clear concise message, no empty
                                               decorative cards



Scan: real progress
Queued → Load models → Analyze photos → Decisions/pricing → Save files →
Completed

Show a compact progress bar, processed photographs, current stage and backend-provided
ETA. ETA starts as unknown and updates from actual timings. Refreshing the page must
restore status.
